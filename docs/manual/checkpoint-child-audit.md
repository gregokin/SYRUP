# Optional private native checkpoint-child audit

`maple_syrup.checkpoint.audit_checkpoint_child` audits the resources and layout of one genuine, still-owned native-written private checkpoint before a separately admitted native load. It is optional: existing `save_checkpoint`, `load_checkpoint`, schema, default bytes, validation order and errors retain their original behavior. It never loads, publishes, resets or advances a model. P3 finish witnesses and P4 transactions are separate work.

Use the source-qualified `default_dense_numpy_wet_v1` P1 profile only: unfinished exact `EventProgress`, Dense NumPy, upwind/array/bisection, normal commits, no phase/history/windowed storage, and existing64cell/6class/16voxel/4096report/10000storm-step bounds. P1 limits retain1GiB summed uncompressed NPY bytes,32MiB JSON,256members/archive and the existing metadata bounds. A source/runtime/metadata/compiled/environment/origin qualification of the COMPLETE new65-row development runtime is mandatory before use. Old locks and receipt identities are not rebound.

The caller first admits all retained input/state/native validation/graph/snapshot/metadata/serialization/error-frame owners. Obtain a genuine `CheckpointWriteBudget`, call the unchanged native writer, retain its input unchanged, and select that exact private three-file child under ordinary caller custody. Record a tuple of `CheckpointRawFile` for `checkpoint.json`, `maple_state.npz`, `continuation.npz` IN THAT ORDER. Before the caller's three actual hashes, stat/check exact regular names, per-file P1 raw sizes and their aggregate. Each record holds its name, size, actual SHA256, device/inode/mtime_ns/ctime_ns/mode and the same directory device/inode/mtime_ns/ctime_ns. Neither these records nor a layout prove that an arbitrary producer ran the native writer.

Call:

```python
audit_checkpoint_child(path, item, context, column, sediment, identity,
                       limits=limits, expected_layout=budget, raw_files=records)
```

The helper validates bounded held metadata, absolute plain path, fixed nofollow directory/files and all exact RAW sizes/aggregate BEFORE hashing, input rerecapture, JSON reads or ZipFile construction. It checks three real hashes, recomputes the actual P1 descriptor, runs ONE unchanged WRITE encoder, builds the shared original six-key native manifest and compares native-formatted RAW JSON bytes. P2 never parses JSON. It then calls the original MAPLE physical checkpoint `_audit_archive` twice, with the second allowance reduced by the first archive's NPY bytes, and matches exact ordered occurrence names/dtype/shape/member bytes to P1. Every serialized occurrence stays separate even when caller arrays share backing. Final stat/inventory observations must still match.

The frozen `CheckpointChildAudit` holds only schema/profile/NumPy version, actual raw records and both observed member tables/byte totals, plus named bounded metadata/hash/call increments. It has no model arrays, native progress, stream or finish certificate. Its metadata counters are not a whole-heap admission. The caller may separately admit and call unchanged `load_checkpoint(..., allow_complete=False, max_bytes=...)`; native decoder, graph reconstruction and physical validation remain mandatory independent authority.

The resource ledger must count both P1 calls, both real WRITE encodes, three graph digests over write/audit/load, ten sequential native file-hash calls including the caller seal, two simultaneously live1MiB hash blocks, P2zero JSON parses versus native loadone, six archive constructions, actual25snapshot-member reads from22members, companion decoded/copied overlaps, and all native graph/validation/JSON/header/text/error-frame owners. Hash count assumes no additional caller rehash; each extra observation is additive. Native ZipExtFile header reading can prefetch data. A maximum-profile child need not fit a4GiB worker; refuse rather than alter limits. The caller's finite AS/RSS/CPU/wall/disk/headroom policy is additional to wire limits.

This is operational resource custody of a genuinely selected unchanged private child, not arbitrary uploaded-archive security, descriptor-atomic IO or a hostile-concurrency theorem. Parent directories/producer/source ownership remain caller obligations. Own bounded custody/layout mismatches raise short `SedimentEventError`. Existing native encoder/audit exceptions, including native `PhysicalCheckpointError` and leading stat `OSError`, propagate unchanged; failure returns no positive audit. Helper contexts close; retained traceback/caller frames can keep metadata/input owners until worker cleanup. It does not change the input or child, normalize a competing JSON representation, materialize deep storage, or duplicate the NPY/ZIP/physical codec.
