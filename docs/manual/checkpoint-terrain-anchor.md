# Loading a wet continuation with an existing static terrain reference

`load_checkpoint(..., terrain_anchor=reference)` optionally retains the caller's exact static `TerrainReference` in the restored wet continuation. The decoded reference must match all ten native fields, including every array byte and floating-point sign bit. This is an identity-preserving LOAD option; it does not rebuild a bed or start, commit, reroute, finish or reset an event.

Omitting `terrain_anchor`, or passing `None`, keeps the existing LOAD behavior and error order. SAVE, the checkpoint schema, P1 layout admission, P2 child audit, graph/source digests, physical validators and resource limits are unchanged.

The first supported anchor profile is a NumPy dense-bed, dense-phase or upwind wet `EventProgress`. The exact frozen native `TerrainReference` class has five arrays and five scalar/policy fields. Arrays must own their data, be readonly, native-endian, C-contiguous and have the native float64/bool dtypes and padded/interior shapes. A valid native reference with Fortran layout, a view or writable arrays is explicitly refused by this optional profile. LOAD never repairs, coerces or copies an anchor. The requested target must be NumPy and `allow_complete` must be exactly `False`. CuPy, windowed/deep storage, CSR phase and completed-handoff anchors are outside this profile.

Argument metadata is checked after the original `max_bytes` and target checks and before checkpoint file access. The five arrays have total raw bytes `T = 9*(ny+2)*(nx+2) + 17*ny*nx`; `T` must fit the caller's existing validated `max_bytes`. The default is still 1 GiB, and the original explicit positive-integer byte-bound contract is unchanged. This bounds the extra read frame; it is not a memory-fit estimate.

LOAD first reconstructs and checks the saved routing source, graph, digest, binding, network and phase using the decoded saved terrain. It then compares the constructed decoded `TerrainReference` to the anchor. Scalars have exact types and float bits; arrays use bounded borrowed byte views, including signed-zero and boolean storage bytes. Only the newly owned decoder dictionary is rebound before the native state constructor. No issued state, original reference, array, flag, graph or saved routing source is mutated. The complete decoded payload must contain exactly one bound state and an exact wet root before it can be returned.

On successful NumPy LOAD, `restored.result.state.terrain is reference`. The existing native continuation and finalization carry the same terrain reference into the resulting state and eventual dry handoff. Original physical and completion rules still decide whether continuation is accepted. This option supplies no automatic combined-model publication, routing-holder migration or exactly-once receipt protocol.

The caller-held anchor and decoded static arrays coexist. A graph may retain decoded leaves after rebinding, so those leaves must remain budgeted. One genuine wet-state comparison reads `2*T` bytes. Malformed multi-state input may compare more before the mandatory whole-tree refusal; its cumulative comparison reads are bounded by twice the original summed uncompressed input `U`. Fixed metadata and borrowed views are additional to all original snapshot, graph, companion, validator and failure-frame lifetimes. No extra numerical array, file or graph is created by the hook. Whole-worker heap, JIT and runtime fit remain the caller's separately qualified responsibility.

A new or modified source implementation requires its own source/runtime qualification. Passing an anchor does not waive source identities, backend checks, Native validation, storage guards or conservation bounds, and it does not qualify combined active-event restart, GPU, windowed or production behavior.
