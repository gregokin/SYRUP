`FloatingPondVertical.from_held_context(context, *, available_bytes_fn, reserve_bytes=0, batch_cells=..., memory_budget_bytes=None, host_memory_budget_bytes=None, host_reserve_bytes=0, host_available_bytes_fn=None)` now also serves a genuine CUDA H0 `/2` `HeldContext` (production edits only in `floating_pond.py` and `floating_pond_cuda.py`).
* Order: exact `HeldContext` class + private minted registry BEFORE any read; backend/quota strictness (a CPU context REJECTS every CUDA-only argument; a CUDA context must be `context.backend == "cuda"`); all shared attributes (`config, backend, _owner=None, _held, _initial=None, _registry={}, _provisional=None, stats, shape, n_layers/n_cells/area, identity, available_bytes_fn`) are set BEFORE the branch; then `floating_pond_cuda.init_cuda_held`.
* Shared water-free CUDA setup: `floating_pond_cuda._set_models` is the setup extracted from `init_cuda` (current-device gate FIRST, shared attributes, the composed device/host stage models from the actual operation terms). The native-owner constructor uses it unchanged (same formulas, `initial_depth_copy=True`); the held path differs only in the retained term (`(L N + N) 8`: zero rows only, no sealed initial depth copy because D0 is referenced). No numerical body copied or changed.
* Held constructor: ONE two-pool admission (device `available_bytes_fn`/`reserve_bytes`/budget; host `host_*`; reserves once via `fcu.admit`) before any array; the only owned arrays are the two device zero rows. D0/mask live in the caller-owned context (device column maps, sealed host `host_active`, HOST `edges_m`): referenced, no D2H, no H2D, no cold payload copy; the context itself is excluded from the models (caller-owned).
* The vertical has NO initial payload: `initial_soil_water`, `initial_state`, `check_initial` are typed refusals; `held_template()` returns the context's exact column/matrix/pref/D0/Ks/generation/source witness. A CUDA `floating_resume` prepare and any current-W adoption/file restoration remain unqualified later tasks; the factory alone is a pure law context and claims no physical restart.
* Tests: host tests (interface strictness, ordering, model arithmetic of the shared setup restated independently); GPU definitions (unrun) for L = 1/3/65, preferential none/enabled/disabled, explicit/texture-Ks, Dense and genuine Windowed origins, current-device-before-readers, two-pool zero/need-1/exact/reserve-once, zero counted transfers and only the zero rows allocated, N = 50003 true allocator peak and released plateau.
