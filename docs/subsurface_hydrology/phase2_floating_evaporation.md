# Phase 2 G3 S0 — shared E-only law body and the floating evaporation adapter

> **Current status pointer (final documentation draft, 2026-11-13).** The text below is the author's original record and is preserved unchanged, including its "author-written / unrun" wording. Root's actual qualification of this component, with its exact tested scope and source identities, is in `phase2_floating_evaporation_acceptance.json`; where the two differ, that receipt governs. No whole-phase acceptance, publication or field validation is claimed by this page.

* `soil_evaporation._stage_laws(xp, part, pet, cover, surface, dt, active, area, n_active)` is the ONE law body, extracted verbatim from `stage_evaporation` (arithmetic, reduction order, packet, ledger unchanged). The fixed `stage_evaporation` keeps its genuine-`SoilColumn` checks, evaporation-factor-1 rule, dynamic metadata, real preflight and admission; its results are bit for bit unchanged (golden hashes computed from the PRE-extraction source). The body is not a validation bypass: it re-checks namespace type, float64, C-contiguity, `(N,)` shape, boolean mask, finite `dt >= 0`, positive `area`, `0 <= n_active <= N`. `n_active=None` (device mask) adds the active count as a twelfth entry of the same single host read.
* `floating_evaporation.py`: `prepare_floating_evaporation(column, partition, ...)` -> minted, uncopyable `FloatingEvaporationOperator`; `stage_floating_evaporation(operator, pet_terrain_m_s, cover, surface_water_m, dt_s, ...)` -> the existing `StagedEvaporation` (`native_step_kwargs()` feeds `floating_soil_layers.floating_step`). Order: genuine `FloatingSoilColumn` (CUDA: current device first), column `evaporation_factor == 1.0` exactly (factor once; `partition.soil_factor` is the EcoHyD factor), exact inputs of the column's namespace/device, strict quota, admission, law body. Existing `EvaporationPartition`, `SurfaceEvaporationLedger`, `StagedEvaporation`, `EvaporationMemory` are reused.
* Memory (modelled, not whole-process): fixed model for `N` cells + `INTERPRETER_ALLOWANCE_BYTES` (64 KiB) on the host side; CUDA: compute = device bytes (current-device reading, device reserve once), host = packet (+8 for the device count) + allowance (host reading, host reserve once). No water, map or input is downloaded or hashed.
* Limits: CPU (NumPy/Numba) executed; CUDA written and unrun (definitions in `tests/phase2_floating_evaporation/test_gpu_definitions.py`); no daily owner, cadence, Pond, wind or new physics.

Root independently accepted this bounded adapter: 26 new CPU tests, 27 existing evaporation tests, 26 source guards, three actual GPU tests, 24 bit-exact comparisons against the pre-extraction laws, and a 50,003-cell device allocation/transfer control. See phase2_floating_evaporation_acceptance.json. This is not yet the floating daily lifecycle or its output hook.
